# Demo strings contract

| Key | FR | EN | Where |
|---|---|---|---|
| `demo_mode_title` | Mode démo | Demo mode | Demo controls title |
| `demo_mode_body` | Simule la date et l’heure. | Simulates the date and time. | Demo controls, under the title |
| `demo_next_moment` | Moment suivant | Next moment | Button that advances the simulated clock |
| `demo_exit` | Quitter le mode démo | Exit demo mode | Button that turns demo mode off |
| `demo_blocked_real_underway` | Un itinéraire est en cours. Terminez-le pour activer le mode démo. | An itinerary is underway. End it to turn on demo mode. | Shown when demo mode cannot turn on because a real Itinerary is Underway. Next step: end it |
| `demo_error` | Action démo impossible. | Demo action failed. | Failure of a demo action, shown beside `action_retry` (Réessayer / Try again) |
